# TradePulse24 5.4 — обновяване

[Изтегли пакета за съществуващ сайт](https://github.com/Bonevv/TradePulse24/raw/refs/heads/downloads-v5.4/TradePulse24-5.4-update.zip).

Проверки преди нов вход с текущи Bid/Ask от брокера, валидни 60 секунди, история по инструмент, новини, разходи и общ риск. Нов панел показва начални и текущи SL/TP, преместване на стопа и изходите по стратегията. Положителната проверка не доказва бъдеща доходност.

Направи резервни копия. Разархивирай пакета и качи съдържанието в PHP хостинга със замяна на кодовите файлове. Не изтривай съществуващия сайт. Ключовете, ценовата история, собствените резултати и дневниците се запазват. Презареди с Ctrl+F5 и провери файловете от Лабораторията. Само публикуване на Worker в Cloudflare не обновява интерфейса на PHP сайта.
