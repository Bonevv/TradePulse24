# TradePulse24 4.9 — пакет за обновяване

[Изтегли TradePulse24-4.9-update.zip](https://github.com/Bonevv/TradePulse24/raw/refs/heads/downloads-v4.9/TradePulse24-4.9-update.zip).

Разархивирай пакета и качи съдържанието в папката на съществуващия сайт със замяна на едноименните кодови файлове. Не изтривай сайта преди качването. Ключовете, ценовата история, работните резултати и личните чернови остават на място.

Преди обновяването запази сървърно копие и копия на локалните журнали. След качването презареди с Ctrl+F5 и провери файловете от Лабораторията.
