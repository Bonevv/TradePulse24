# Ако Пулс не отговаря

Първоначалната версия показваше общо съобщение за различни PHP и Gemini грешки. Обновените PHP файлове показват конкретен код, без ключове, сурови отговори от Google или съдържание на личния дневник.

Влез в Лабораторията, отвори „Пулс · проверка на Gemini“ и натисни „Провери Gemini“. Проверката извлича достъпните модели, без да генерира анализ. Успешният списък не означава, че квотата за генериране е свободна.

| Код | Какво да провериш |
| --- | --- |
| `not_configured` | Ключът трябва да е в `GEMINI_API_KEY` в средата на PHP или в `gemini_key` в локалната конфигурация. |
| `invalid_key` / `expired_key` | Провери ключа в Google AI Studio. Въведеният ключ и PHP конфигурацията трябва да са за същия проект. |
| `key_restricted` | Провери ограниченията по приложение, IP и API в Google Cloud. Ключ, ограничен само до браузърни referrer адреси, не е подходящ за заявката от PHP. |
| `access_denied` | Провери разрешенията за Generative Language API и наличността от региона на хостинга. |
| `model_not_found` / `invalid_model` | Избери налично име от проверката и го задай в `GEMINI_MODEL` или `gemini_model`. Не поставяй ключа в полето за модел. |
| `provider_quota` | Google е върнал 429. Провери квотата за модела и проекта в AI Studio. Нов ключ от същия проект не създава нова квота. |
| `site_quota` | Достигнат е локалният лимит на сайта. Той е отделен от квотата на Google. |
| `cache_unwritable` | PHP потребителят трябва да може да записва в `data/private/`. Запази забранения HTTP достъп и не използвай общодостъпни права 777. |
| `curl_missing` | Включи cURL в PHP конфигурацията, използвана от Apache. PHP в конзолата може да използва различен `php.ini`. |
| `tls_error` | Обнови доверените CA сертификати и настройките `curl.cainfo` / `openssl.cafile` в PHP. Не изключвай проверката на сертификатите. |
| `connection_failed` / `timeout` | Провери изходящия HTTPS достъп до `generativelanguage.googleapis.com`, защитната стена и proxy настройките. |
| `request_rejected` | Провери модела и дали са обновени всички API файлове. Някои модели не приемат еднакви настройки за thinking или структуриран отговор. |
| `response_truncated` / `invalid_analysis` | Моделът не е върнал завършено структурирано обяснение. Пробвай достъпен Flash модел и актуалните PHP файлове. |
| `analysis_busy` | Вече се чака друга заявка. Изчакай да приключи, преди да натиснеш пак. |

При достъп до конзола можеш да изпълниш от папката на проекта:

```sh
php tools/check-gemini.php
```

Командата показва версията на PHP, наличието на cURL и достъпните модели. Ключът остава скрит.

При обновяване пази `api/config.php`, `api/config.local.php` и цялата папка `data/`. След копиране на корекцията презареди страницата с Ctrl+F5. Ако PHP продължи да изпълнява стар код от OPcache, рестартирай локалния Apache/PHP процес или използвай механизма за обновяване на хостинга.
